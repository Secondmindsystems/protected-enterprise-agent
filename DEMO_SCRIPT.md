# 10–15 Minute Technical Demo Script

## 0:00–1:30 — Thesis and trust map

Show `ARCHITECTURE.md`. State the tested claim: the prototype preserves business utility while denying enumerated raw synthetic identifiers to tested model-facing and application-controlled surfaces.

## 1:30–3:00 — Vendor reality

Show the pinned upstream SHA and component versions. Start the two official local stacks. Run the vendor samples or direct documented API calls and show actual, unscripted response shapes.

## 3:00–5:00 — Sensitive source to protected index

Show one fictional source fixture in the trusted raw zone. Run ingestion. Show Data Discovery entity classes, then show the protected stored record and non-sensitive metadata. Do not display the leak manifest contents on screen.

## 5:00–7:00 — Legitimate support task

Run scenario S1. Show that protected retrieval preserves the service tier, state, case, and policy action. Show the exact dispatch assertion and useful response. Open the utility result.

## 7:00–9:00 — Exfiltration and prompt injection

Run S2 and S3. Show the observed Semantic Guardrails score/labels and the deterministic application decision. Confirm that blocked requests never call the model.

## 9:00–10:30 — Direct PII and fail-closed behavior

Run S4 with fictional direct user PII and show pre-dispatch transformation. Then stop or misconfigure a required provider and run S7. Show explicit failure, zero raw forwarding, and sanitized error evidence.

## 10:30–12:00 — Independent proof plane

Run the canonical tests and leak scanner. Open the machine-readable security, adversarial, utility, fail-closed, provenance, and evidence-integrity results. Emphasize that the scanner searches exact canaries rather than trusting application narration.

## 12:00–13:30 — Reproducibility and limits

Show clean-clone setup, the frozen commit, and `KNOWN_LIMITATIONS.md`. State clearly that this is a prototype; application surrogates are not Protegrity tokenization; and tested absence is scoped to enumerated fixtures and surfaces.
